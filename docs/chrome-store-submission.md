# Chrome 应用商店上架指南（LX 矩阵插件）

这份文档把上架要填的内容都准备好了，照着复制粘贴即可。**只有注册账号、付费、点提交需要你本人操作**，其余素材都已就绪。

## 0. 你需要亲自做的两件事

1. **注册开发者账号**：打开 <https://chrome.google.com/webstore/devconsole>，用 Google 账号登录，付 **$5 美元**一次性注册费。新账号可能要做邮箱/身份验证。
2. **最后点「提交审核」**：在你账号的后台里。

## 1. 上传哪个包

上传 **`public/lx-matrix-extension-store.zip`**（生产版，已去掉 localhost 权限，审核更顺）。

> `public/lx-matrix-extension.zip` 是给社群「解压加载」用的开发版，**不要**传这个。
> 重新生成商店包：`cd extension && npm run pack:store`。

## 2. 商店列表（Store listing 标签）

- **名称（Name）**：`LX 矩阵 · 流量矩阵助手`
- **简短摘要（Summary，≤132 字符）**：
  ```
  LXDAO 蓝V互推社群助手：成员新帖自动进入待互动队列并角标提醒，在 X 上识别矩阵成员并一键记录互动。
  ```
- **详细描述（Description）**：
  ```
  LX 矩阵是 LXDAO 蓝V互推社群的协作工具，帮助成员之间高效互推、形成流量矩阵。

  功能：
  • 动态打卡队列 —— 聚合所有已审核成员的近期原创推文，待互动的排前面，互动完一键打卡，已互动的自动变灰。
  • 角标提醒 —— 后台每 30 分钟刷新，工具栏角标显示近 24 小时还没互动的成员推文数，清零即今日任务完成。
  • X 现场识别 —— 在 x.com 时间线上自动给矩阵成员的推文打标；在成员推文里点赞/转推/回复时自动记录互动，无需回到面板。
  • 成员监控 —— 一眼看到每位成员今天有没有发帖。

  说明：
  • 仅 LXDAO 已通过审核的社群成员可用，需在网站生成的扩展令牌登录。
  • 插件只做提醒和记录，所有互动均由你本人手动完成，不会自动点赞或转推。
  • 不收集你的私信或非公开内容，仅读取公开推文信息。详见隐私政策。
  ```
- **类别（Category）**：社交与通讯（Social & Communication）
- **语言（Language）**：中文（简体）
- **图标**：自动取自包内 `icon-128.png`，无需另传。

### 截图（必填，至少 1 张）

尺寸 **1280×800** 或 **640×400**（PNG/JPEG）。建议放插件面板的「动态打卡队列」和「成员监控」两张。
> 登录走通后可让 Claude 用浏览器自动截标准尺寸图；或自己截图后用工具裁到 1280×800。

## 3. 隐私实践（Privacy practices 标签）

- **隐私政策 URL**：`https://lx-matrix.vercel.app/privacy` （已上线，公开可访问）
- **单一用途（Single purpose）**：
  ```
  帮助 LXDAO 互推社群的已审核成员发现彼此的新推文并记录互动，形成互推矩阵。
  ```
- **权限理由（逐条填）**：
  | 权限 | 理由 |
  |---|---|
  | `storage` | 在本地保存服务地址、成员扩展令牌和缓存。 |
  | `alarms` | 每 30 分钟定时刷新待互动数量并更新工具栏角标。 |
  | 主机权限 `lx-matrix.vercel.app` | 调用本社群后端读取成员动态、上报互动打卡。 |
  | 内容脚本 `x.com` / `twitter.com` | 在时间线上识别成员推文并就地记录互动；仅读取页面已公开的作者与推文链接。 |
- **远程代码（Remote code）**：否（不加载外部脚本）。
- **数据收集声明**：勾选「身份信息（公开账号资料）」「网站内容（公开推文信息）」「用户活动（互动记录）」。三项认证全部勾上：
  - 不出售/转让给第三方（与征信用途无关）；
  - 不用于与单一用途无关的目的；
  - 不用于判定信用资格/放贷。

## 4. 可见性（Visibility）

选 **不公开（Unlisted）**：有链接才能安装，搜索不到，适合小而精的私密社群。照样一键「添加至 Chrome」+ 自动更新。

## 5. 提交后

- 审核通常几小时到几个工作日。权限已收窄，会比较快。
- 被拒会说明原因，改完再传即可。
- 通过后把商店链接发群里，成员点「添加至 Chrome」即装好。

## 6. 以后更新

1. 改 `extension/public/manifest.json` 里的 `version`（如 `0.2.1`）。
2. `cd extension && npm run pack:store`。
3. 后台传新的 `lx-matrix-extension-store.zip` → 提交。用户会自动更新。
